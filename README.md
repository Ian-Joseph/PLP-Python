# PLP-Python

This repository contains the assignments and exercises for the 8-week Python course (PLP), starting from Week 1.  
It is a collection of scripts and activities made while learning Python.

---

## 📁 Repository Structure

```

PLP-Python/
│
├── activity_2.py
├── week1.py
├── week2.py
├── week3.py
├── week4.py

├── week7.py
└── README.md

````

- **activity_2.py** — supplementary/bonus activity  
- **week1.py** … **week7.py** — solutions, exercises and tasks for each week  
- **README.md** — this file

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your machine  
- Basic familiarity with running Python scripts from the command line  

### How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Ian-Joseph/PLP-Python.git
   cd PLP-Python
   ````

2. Run any of the weekly scripts. For example:

   ```bash
   python3 week1.py
   ```

   or

   ```bash
   python week3.py
   ```

3. You can also open the files in your editor / IDE to read, modify, or expand the code.
